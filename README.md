# 🧠 생성형 AI 서비스 (Generative AI Services Overview)

## 📌 개요 (Overview)
생성형 AI(Generative AI)는 텍스트, 이미지, 음성, 코드 등 다양한 콘텐츠를 자동으로 생성하는 인공지능 기술이다.  
최근에는 단순 생성 기능을 넘어 **AI 에이전트, 자동화, 멀티모달 처리**까지 확장되고 있다.

## 🤖 AI 에이전트 (AI Agent)

### 📌 정의
AI가 단순 응답을 넘어서 **목표 기반으로 행동을 수행하는 시스템**

### 🔧 주요 기능
- 자동 작업 수행 (파일, 웹, 코드)
- API 및 외부 시스템 연동
- 반복 업무 자동화
